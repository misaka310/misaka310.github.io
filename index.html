ローカルAIと自作PC 動画アップロードツール

個人用の動画アップロードツール（YouTube Data API v3）

このサイトは、YouTubeチャンネル「ローカルAIと自作PC」の運営者が、 自分で制作した動画を、自分のチャンネルへ非公開でアップロードするためだけに使う個人用ツールの説明ページです。 不特定の利用者へ配布するものではなく、利用者は運営者本人だけです。

このツールがすること

  • 制作済みの動画ファイル、題名、概要欄、サムネイル画像を、運営者本人のチャンネルへアップロードします。
  • 公開設定は常に「非公開」で、公開への切り替えは人がYouTube Studioで行います。
  • アップロード以外の操作（動画の削除、コメント、チャンネル設定の変更など）は行いません。

使う権限

Googleアカウントの認可（OAuth 2.0）で使うスコープは https://www.googleapis.com/auth/youtube.upload だけです。 このスコープは、動画のアップロードに必要な最小の権限です。

データの扱い

認可で受け取るリフレッシュトークンは、運営者が管理するパスワード管理サービスにのみ保存し、 第三者へ送信しません。詳しくは プライバシーポリシー をご覧ください。

お問い合わせ

本ツールおよび本サイトに関するお問い合わせは、運営しているYouTubeチャンネル ローカルAIと自作PC（@localai_pc） のコメント欄、またはチャンネルの「概要」に記載の連絡先までお願いします。
