プライバシーポリシー

ローカルAIと自作PC 動画アップロードツール（以下「本ツール」）

本ツールは、YouTubeチャンネル「ローカルAIと自作PC」の運営者（以下「運営者」）が、 自分で制作した動画を自分のチャンネルへアップロードするためだけに使う個人用ツールです。 利用者は運営者本人に限られます。本ポリシーは、本ツールが扱う情報を説明します。

1. 取得する情報

情報内容
認可情報GoogleアカウントのOAuth 2.0認可で発行されるリフレッシュトークン（およびアクセストークン）。動画をアップロードする本人のチャンネルを識別するために使います。
アップロードする内容運営者自身が用意した動画ファイル、題名、概要欄、サムネイル画像。

本ツールは、氏名・住所・電話番号・メールアドレス・連絡先・位置情報などの個人情報を取得しません。 視聴者や第三者の情報も取得しません。Cookieによる追跡やアクセス解析も行いません。

2. 利用目的

  • 運営者本人のYouTubeチャンネルへ、動画を非公開でアップロードするため。
  • アップロードした動画の識別子（動画ID）を記録し、作業の記録として残すため。

3. 保存と安全管理

  • リフレッシュトークンは、運営者が管理するパスワード管理サービス（本人だけが使える保管領域）にのみ保存します。
  • ソースコード、設定ファイル、リポジトリ、ログにトークンの値を書きません。
  • 通信はGoogleのAPIエンドポイント（HTTPS）に対してのみ行います。

4. 第三者への提供

取得した情報を第三者へ提供、販売、貸与しません。広告目的での利用もしません。 情報の送信先はGoogleのAPI（YouTube Data API v3）だけです。

5. 保存期間と削除

  • リフレッシュトークンは、本ツールを使う間だけ保存します。不要になった時点で、保管領域から削除します。
  • 運営者（利用者）は、いつでもGoogleアカウントの サードパーティ製のアプリとサービス から本ツールのアクセスを取り消せます。取り消し後は、本ツールはアップロードできません。

6. YouTube API Servicesの利用

本ツールは YouTube API Services を利用しています。本ツールの利用により、 利用者は YouTube 利用規約 に同意したものとみなされます。 また、Googleの プライバシーポリシー が適用されます。

7. 本ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を書き換えます。

8. お問い合わせ

本ポリシーに関するお問い合わせは、運営しているYouTubeチャンネル ローカルAIと自作PC（@localai_pc） のコメント欄、またはチャンネルの「概要」に記載の連絡先までお願いします。
